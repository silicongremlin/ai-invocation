# AI Invocation

AI Invocation is a compact O/R/T/C model: Objective, Resources, Tolerance (risk plus loss boundary), and Constraints. Plans with vague or incomplete fields are rejected before action.

The Racket game at `implementations/racket/src/IslandAdventure.rkt` is historical lineage. The Python package is the maintained reference implementation; tests are deterministic and require no Colab runtime.

Run: `PYTHONPATH=implementations/python/src pytest implementations/python/tests`.
