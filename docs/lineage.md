# Lineage

The Racket coursework game [CS353-IslandAdventure](https://github.com/kimbrow-slice/CS353-IslandAdventure) established the state machine, inventory, locations, and risk outcomes. The Python/Colab prototype evolved that game and introduced a tutor gate requiring Objective, Resources, Tolerance, and Constraints before a risky action. The maintained Python model extracts that gate independently from presentation. Historical Git history and coursework artifacts are not imported.
